# CatSay
### A small Python utility that might just lift your spirits  
![CatSay Preview](assets/catsay.jpg)  
There’s nothing useful in it just compliments and jokes that might lift your spirits.  
  
## How does this work?
When you open the utility, you are immediately greeted by a cute cat  
that displays a random phrase.

## regarding the development:
Since the project's code is open, you are free to improve the program,  
add phrases, or introduce new features.
